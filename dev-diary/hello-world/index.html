Hello, world (twice)

August 21, 2026

This site now exists. It has two personalities, because I do:

  • AI mode (dark) — agent workflows, LLM research, and student tools.
  • Games mode (light) — everything I’ve shipped as Libo Dev.

The big toggle on the home page flips between them. Under the hood it’s one data-mode attribute on <html> and a single file of CSS custom properties — every color, font, and radius on the site lives in one theme file, so each mode is fully re-skinnable without touching a component.

More posts soon on what I’m actually building.
